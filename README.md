# StudyLens AI 🎓🤖

StudyLens AI is an AI-powered study assistant that helps students turn their PDF study materials into simple, exam-focused learning content.

## ✨ Features

- 📄 Upload study PDFs
- 🤖 AI-powered PDF analysis
- 📝 Generate easy-to-understand summaries
- 🎯 Identify important topics
- 🧠 Smart Revision points
- ❓ AI-generated MCQs
- 🔄 Generate new MCQs from the uploaded study material
- 📱 Responsive and student-friendly interface

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### AI
- Google Gemini API

### PDF Processing
- pypdf

### Environment
- Python virtual environment
- python-dotenv
